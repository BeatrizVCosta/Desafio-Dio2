# Organizador de Declaração de Imposto de Renda 📊🧾

Ferramenta em Excel desenvolvida para organizar, reunir e validar informações essenciais para a declaração de imposto de renda, combinando uma interface amigável de aplicativo com automações em Excel.

## 🚀 Sobre o Projeto
O projeto funciona como um agregador de dados e central de controle, permitindo ao usuário registrar entradas financeiras, gerenciar informes e notas, e navegar de forma fluida entre as seções.

## 🛠️ Tecnologias e Recursos Utilizados
- **Microsoft Excel / Google Planilhas:** Estruturação de dados, tabelas e menus de navegação.
- **Validação de Dados:** Menus suspensos e restrição de entrada para garantir a integridade das informações.
- **Formatações Personalizadas:** Layout limpo, organizado e com visual profissional (estilo aplicativo).
- **Funções e Fórmulas:** Automatizações para cálculo e consolidação de dados.

## 📂 Estrutura da Planilha
- **Menu de Navegação:** Acesso rápido e intuitivo às abas do sistema através de links internos.
- **Formulário do Titular:** Cadastro estruturado de dados pessoais e informações base.
- **Tela de Informes:** Consolidação de rendimentos, informes bancários e fontes pagadoras.
- **Tela de Notas:** Anotações e lembretes cruciais para o preenchimento da declaração oficial.

## 📥 Como Usar
1. Baixe o arquivo `.xlsx` disponível neste repositório.
2. Abra a planilha no Microsoft Excel.
3. Navegue através do menu principal preenchendo os dados do titular, informes e notas de acordo com a sua realidade financeira.
